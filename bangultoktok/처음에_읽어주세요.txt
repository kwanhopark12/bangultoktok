방울톡톡 웹 대시보드 — 처음 설정 순서
=====================================

[1] 컴퓨터에 설치할 것
  - Chrome 브라우저
  - Visual Studio Code (https://code.visualstudio.com)
  - VS Code 확장 프로그램 "Live Server" (왼쪽 네모 4개 아이콘 → 검색 → 설치)
  - (나중에 관수 작업 때) Arduino IDE 2 + ESP32 보드 패키지

[2] 구글시트 준비 (한 번만)
  - 시트 오른쪽 위 [공유] → 일반 액세스 → "링크가 있는 모든 사용자" + "뷰어"
  - 시트 주소에서 /d/ 와 /edit 사이 문자열 복사 (= 시트 ID)
  - 센서 데이터가 쌓이는 탭 이름 확인 (방울톡톡_데이터 시트는 env_log)

[3] config.js 수정
  9번째 줄   SHEET_ID: "여기에_시트ID_붙여넣기",   ← 복사한 시트 ID
  12번째 줄  SHEET_NAME: "env_log",                ← 탭 이름 (이미 env_log 로 되어 있음)
  SOIL_CALIBRATION 부분  ← 센서 보정값 (화분별 공기 중 값 dry / 물속 값 wet)
                           방법은 사이트의 ⚙️ 설정 → 센서 보정 에 있음

[4] 컴퓨터에서 확인
  - VS Code → 파일 → 폴더 열기 → 이 폴더 선택
  - index.html 우클릭 → "Open with Live Server"
  - ⚙️ 설정 → [연결 확인하기] 버튼으로 시트가 제대로 읽히는지 확인

[5] 휴대폰에서 보기 (GitHub Pages, 무료)
  - github.com 가입 → 오른쪽 위 + → New repository
    이름: bangultoktok / Public 선택 → Create repository
  - "uploading an existing file" 클릭 → 이 폴더 안의 파일+icons 폴더를 전부 끌어다 놓기 → Commit changes
  - 저장소 Settings → Pages → Branch: main / (root) → Save
  - 1~2분 뒤 주소: https://내아이디.github.io/bangultoktok/
  - 휴대폰으로 이 주소 열고 "홈 화면에 추가" (방법은 사이트 ⚙️ 설정 화면 맨 아래)

[파일 설명]
  index.html     홈 (나의 식물 / 기록 / 설정으로 이동)
  plant.html     나의 식물 — 실시간 토양수분 게이지 + 온도·습도·햇빛
  records.html   나의 식물의 기록 — 토양수분·온도·습도·햇빛 추이 그래프 + 표
  settings.html  설정 — 기준값, 새로고침 간격, 시트 연결 확인
  config.js      ★ 시트 ID, 화분 설정
  data.js        구글시트 읽기 (열 자동 인식)
  gauge.js       원형 게이지 그리기
  charts.js      추이 그래프 그리기
  style.css      디자인
  manifest.json, icons/   휴대폰 홈 화면 아이콘
