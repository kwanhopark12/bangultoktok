🌡️ 토양수분 기준

화분 상태를 "물 필요 / 촉촉함 / 너무 많음"으로 나누는 기준이에요. 이 기기(휴대폰·컴퓨터)에만 저장돼요.

🚿 자동 관수

관수 시스템을 연결하면, 토양수분이 "물 필요 기준" 아래로 내려갈 때 ESP32가 펌프를 자동으로 켜도록 만들 예정이에요. (A·C 구역 = 센서 기반 자동, B·D 구역 = 정해진 시간 타이머) — 지금은 화면 표시만 됩니다.

📟 토양수분 센서 보정

시트의 soil_pct 열이 비어 있으면, soil_raw(센서 원시값)를 아래 보정값으로 %로 바꿔서 보여줘요. 센서마다 값이 조금씩 달라서 화분별로 한 번씩 재서 config.js의 SOIL_CALIBRATION에 넣어주세요.

  1. 센서를 흙에서 살짝 빼서 공기 중에 1분 들고 있기 → 아래 표의 "지금 센서값" = dry
  2. 센서를 물컵에 흰 선 높이까지 담그고 1분 → "지금 센서값" = wet
  3. config.js 에 A1: { dry: 2650, wet: 1020 }, 처럼 적고 저장

📱 휴대폰 홈 화면에 앱처럼 추가하기

아이폰 (Safari)

  1. Safari로 이 사이트 주소를 엽니다.
  2. 아래쪽 가운데 공유 버튼(□↑)을 누릅니다.
  3. "홈 화면에 추가" → 오른쪽 위 "추가".

안드로이드 (Chrome / 삼성 인터넷)

  1. Chrome으로 이 사이트 주소를 엽니다.
  2. 오른쪽 위 ⋮ 메뉴 (삼성 인터넷은 아래 ≡ 메뉴)를 누릅니다.
  3. "홈 화면에 추가" 또는 "앱 설치"를 누릅니다.
